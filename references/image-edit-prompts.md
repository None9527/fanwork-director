# 关键帧 edit prompt 写法

目的：以**角色参考图为相貌基准**，产出符合分镜构图的视频首帧关键图。
产出的图将直接作为 I2VA/FL2VA 的 first_frame，因此构图即承诺——prompt 里
描述多少，视频模型就在画面里找到多少起始状态。

## 结构模板（四段，顺序固定）

```
[BASE] 风格基线：与题材原作一致的 3D 写实渲染风格，电影质感，16:9 画幅，
       色调：<场景色>。保持参考图角色相貌特征完全不变。
[SUBJECT] 逐字粘贴 cast.md 的该角色外观锁定串 + 本镜中的动作相位与画面位置。
[SCENE] 环境、时间、天气、背景元素、其他角色及其相对站位。
[LIGHT/CAMERA] 光源方向与色温、景深、镜头焦段感（广角/中长焦）、构图法则（三分/对称/引导线）。
```

要求：

- 描述**一个冻结瞬间**（静态构图），不要描述运动过程——运动是 Phase 4 的事。
- 角色动作取"可延续相位"：爪将抬未抬、话到嘴边——便于视频从首帧正向发展。
- 多角色镜头：每个角色分别引用各自参考图并在 [SUBJECT] 分段声明，防止相貌融合。
- 与场景既有光源方向一致（查 ledger.md），同场景关键帧之间色温不得漂移。
- 负面约束写在文末一行：no text, no watermark, no extra characters。
- 若角色参考图本身是游戏 UI 截图（图鉴/游记页带文字排版，如影神图库），负面约束必须加
  `no UI elements`，并在 [BASE] 段声明"与参考图角色志趣一致"而非"完全复刻参考图画面"，
  防止把卷轴、按钮、水印生成进关键帧。

## 示例（黑熊精·观音禅院夜）

```
[BASE] 与参考图一致的3D写实游戏渲染风格，电影质感，16:9，冷蓝夜色中透暖红火光。
      保持参考图中黑熊精的相貌、毛色与甲胄细节完全不变。
[SUBJECT] 黑熊精（黑棕长毛、金甲、长枪——cast.md 锁定串原文）立于画面左三分之一，
      面朝右，双爪垂握枪杆，头微低，鼻翼翕动嗅向火光方向。
[SCENE] 观音禅院后院，烧毁的廊柱与余烬，远处正殿火光冲天，夜空无月。
[LIGHT/CAMERA] 主光为右后方低角度橙红火光（轮廓光勾毛边），补光冷蓝天光；
      中长焦浅景深，背景余烬虚化。
负面：no text, no watermark, no extra characters。
```

调用：

```bash
python3 scripts/image_api.py \

```
